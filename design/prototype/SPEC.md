# 家庭财务复盘 · UI/UX 重设计原型规格

目的：用可点击的 HTML 原型验证新的信息架构（IA）与关键交互，供用户评审。原型是一次性的，不进入 App 代码。

## 通用约束

- 单文件 HTML（内联 CSS/JS），无外部依赖、无网络请求、无构建步骤；双击即可在 Safari/Chrome 打开。
- 数据只来自同目录 `data.js`（`window.MOCK`），通过 `<script src="data.js"></script>` 引入。不要改 `data.js` 的结构；需要派生数据时在页面内计算。
- 界面语言：简体中文；技术名词可保留英文（如 FIRE）。
- 视觉：原生 macOS / iOS 克制风。
  - 字体：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", sans-serif`；金额用 `font-variant-numeric: tabular-nums`。
  - 强调色 teal `#30B0C7`（深色 `#40C8E0`）；语义色：待处理 orange `#FF9F0A`、错误 red `#FF453A`、草稿 blue `#0A84FF`、已确认 green `#30D158`。
  - 系统灰阶背景、细分隔线、圆角 10–12px、少阴影。图标可用 inline SVG 或 Unicode 符号近似 SF Symbols，保持统一线性风格。
  - 支持 `prefers-color-scheme: dark`。
- 文案：每个页面说明不超过一句；较长解释放到 ⓘ 按钮弹出的 popover 中。
- 金额格式 `¥1,234.56`；负数/退款用 `−¥`。
- 所有按钮都要有可见反馈：保存类操作更新内存中的 mock 状态并弹出 toast（「已保存 · 撤销」可点撤销）。不需要持久化。

## 共享组件（两端统一的设计语言）

| 组件 | 说明 |
| --- | --- |
| `MetricTile` | 标题（secondary）+ 大号数值 + 一行注释 |
| `SectionCard` | 标题 + 可选 ⓘ + 内容；白底（深色为二级背景）圆角卡片 |
| `StatusBadge` | 胶囊小标签：待分类 / 待核事实 / 退款候选 / 关联复核 / 来源归并 / 草稿 / 已确认 |
| `Chip` | 可选中筛选 chip，带计数 |
| `EmptyState` | 图标 + 一句标题 + 一句说明 |
| `Toast` | 底部居中，3 秒消失，可带「撤销」 |
| `InfoButton` | ⓘ，点击显示 popover 长解释 |

## 信息架构

四块：**概览 / 待办 / 交易 / 规划**，加上设置（Mac）/「我的」（iPhone）。

- 「待办」= 单一统一队列，类型 chips 筛选：全部、待分类、待核事实、退款候选、关联复核、来源归并。默认「全部」，按金额从大到小，金额未知排最后。「历史」切换显示：暂放、本次已保存、已确认、已排除。
- 系统类事项（同步冲突、待解析录屏、发往 Mac 的请求、处理器校验失败）不进待办，进 toolbar「状态中心」。
- 「交易」顶部 scope：**交易 ｜ 原始资料**。原始资料 = 原始记录与订单卡片浏览（按来源平台筛选）；已归入交易的原始记录可一键「查看所属交易」。
- 取消独立的「交易证据」tab。未挂到交易的关联候选进入待办「关联复核」。

## Mac 原型（`mac.html`）

模拟一个 1280×820 的 macOS 窗口（带红黄绿交通灯、统一标题栏 toolbar），居中显示在浅灰桌面背景上。窗口内部可交互。

### 窗口骨架
- 左 sidebar（约 220px，半透明材质感）：
  - 第一组：概览、待办（右侧计数 badge）、交易
  - 第二组「规划」：目标与情景、买房与子女、模型参数
  - sidebar 底部：家庭名称 + 当前设备角色小字（「家庭 Mac · 主机」）
- Toolbar（标题栏右侧）：期间选择器（下拉：本月 / 上月 / 今年 / 近 90 天 / 全部 / 自定义…，仅概览与交易页显示）、「导入」按钮、状态中心图标（有问题时带红点）、刷新按钮。
- 拖拽导入：在窗口任何位置 dragover 时显示全窗 overlay「松开以导入账单与素材 · 支持 PDF、CSV、XLSX、图片、录屏」，drop 后 toast「已加入处理队列：N 个文件」。另提供一个隐藏的演示按钮（例如在导入按钮菜单里「模拟拖入」）以便无文件也能看到 overlay。
- 状态中心 popover：分组列出 `MOCK.system` 中的事项（同步、请求、录屏解析、冲突），每项有状态图标、一句描述、行内操作按钮（重试 / 处理冲突 / 立即同步）。点击操作后更新状态。
- ⌘, 或 sidebar 底部齿轮打开「设置」窗口（模态覆盖层模拟一个独立的 macOS Settings 窗口，顶部图标 tab）：通用、家庭、分类与标签、同步、备份与维护。每个 tab 放代表性控件即可（成员列表、账户列表、分类树、同步目录与状态、备份按钮），不必全部可用。

### 概览
- 若有严重系统事项：顶部 banner（橙色细条）「有 1 个同步冲突待处理」+「处理」。
- 第一行 MetricTile ×3：净消费（含与上期差额）、待关联消费、完整月份月均。
- 待办卡：「还有 N 项待处理 · 涉及 ¥X」+ 各类型计数 chips，点击 chip 跳到待办并预选该类型。
- 月度趋势柱状图（纯 SVG/CSS），当前不完整月份用橙色；点击柱子跳到交易并把期间设为该月。
- 支出结构：一级分类横向条形排行，可展开二级分类；点击二级跳到交易并带该分类筛选。
- 标签视角：前 6 标签与金额，附 ⓘ「标签可重叠，金额不可相加」。

### 待办（核心页面，三栏）
- 左栏队列（约 300px）：顶部类型 chips（带计数，可横向滚动或换行）、搜索框、「待处理 / 历史」分段控件；「包括区间外与日期未知」作为队列菜单（…）中的开关。行：标题、日期、金额（右对齐）、缺项 StatusBadge；有草稿显示蓝点。选中行高亮。
- 中栏编辑器：
  - 头部：标题、金额、日期、来源平台；
  - 「分类推荐」：最多 3 个 chip，带序号提示 `1` `2` `3` 与相似度；点击即采用；
  - 分类：一级/二级两个下拉；
  - 支出性质：分段控件「持续生活支出 / 一次性购买」；
  - 标签：token 输入（回车添加、× 删除）；
  - 消费人 / 支付账户：下拉；
  - 若类型为「待核事实」：显示「核实事实」卡片（统计处理、日期、金额更正）。
- 右栏证据：来源选择 segmented（若多份），原件预览（用灰色占位块 + 模拟的票据文字；订单卡片用竖长占位），原始文字等宽字体块，「打开原件」按钮；若有关联候选：候选卡片列出两侧记录，按钮「支持关联」「排除」「仍需资料」。
- 底部操作条：左侧消息区（草稿提示 / 上次保存）；右侧「撤销上一笔 ⌘Z」「暂放 ⌘D」「保存并下一笔 ⌘↩」（主按钮）。
- 键盘：`j`/`↓` 下一项、`k`/`↑` 上一项、`1`–`3` 采用推荐、`⌘↩`/`Ctrl↩` 保存并下一笔、`⌘D` 暂放、`⌘Z` 撤销、`⌘F`/`/` 聚焦搜索、`?` 显示快捷键面板。输入框聚焦时字母快捷键不触发。
- 保存后：条目从待处理移入历史「本次已保存」，自动选中下一项，toast「已保存 · 撤销」。
- 队列清空：EmptyState「全部处理完了」+ 去历史复查的链接。
- 「来源归并」类型条目的编辑器换成：保留银行记录列表 / 另一来源记录列表 + 「确认整组归并」「拒绝归并」。

### 交易（两栏）
- 左列表：scope 分段「交易 ｜ 原始资料」；搜索；筛选菜单（账户、一级分类、标签、视图：全部消费/待处理/账户待关联/资金流），已生效筛选显示为可移除 chips；列表按日期分组，组头显示当日合计。行：标题、分类·账户小字、金额、标签（最多 3）。
- 右详情：标题、金额大字、日期·状态；信息网格（分类、性质、消费人、支付账户、通道、标签）；「编辑」按钮打开与待办相同的编辑器（sheet 形式）；「生命周期」时间线（支付 / 退款 / 银行扣款，每个节点日期、来源、金额）；「原始证据」折叠区（复用证据组件）；「从补全和统计中排除」开关放在页面底部「更多」区。
- 原始资料 scope：列表行为平台 icon + 日期 + 金额 + 标题；平台筛选 chips（微信、支付宝、美团、云闪付、银行、订单卡片）；详情为证据组件，若已归入交易则显示「查看所属交易 →」。

### 规划
- 目标与情景：MetricTile ×3（FIRE 目标资产、当前可投资资产、预计达成年龄）、收益率情景折线图（4/6/8/10%）、回撤下的生活预算表。
- 买房与子女：两张可开关的情景卡，开启后显示结果 MetricTile。
- 模型参数：分组表单（资产与投入、生活成本与收益假设、储备桶、一级年度预算），底部「保存参数」主按钮，次要操作（导入/导出/恢复/清空）收进「…」菜单。

## iPhone 原型（`ios.html`）

在页面中央模拟一部 iPhone（393×852 逻辑尺寸，圆角机身、灵动岛、Home 指示条），内部可交互。机身右侧可放一个小说明面板列出可演示的操作。

目标：**快速查看历史 + 随手补全**。

### Tab bar（4 个）
概览 · 待办（badge 计数）· 交易 · 我的。使用 iOS 原生风格：大标题导航栏（滚动后可不收缩，简化处理即可）、分组列表、底部 tab bar 带模糊材质。

### 概览
- 导航栏大标题「概览」，右上同步状态图标（点击弹出 action sheet：立即同步 / 查看状态）。
- 期间分段/菜单：本月 · 上月 · 今年 · 近 90 天 · 自定义。
- 净消费大数字 + 与上期差额；下一行小字退款与待关联金额。
- 待办卡（有待办才显示）：「12 项待处理 · ¥3,420」→ 切到待办 tab。
- 月度趋势柱状图；点击柱子 → 切到交易 tab 并带该月筛选。
- 分类排行前 6，点击 → 推入该分类交易列表。
- FIRE 摘要卡（只读）：目标资产、进度条、预计达成年龄 → 推入只读 FIRE 详情。

### 待办
- 顶部类型 chips 横向滚动；列表行：标题、日期、金额、缺项 badge。
- 导航栏右上：「历史」与「＋」（＋ = 发送素材到 Mac，弹出 action sheet：照片 / 文件 / 录屏，选择后 toast「已发送，Mac 处理后自动同步」）。
- 点击行 → 推入补全页（全屏）：
  - 上半：标题金额；分类推荐 chips；分类选择（推入二级列表或 menu）；支出性质 segmented；标签 token；消费人/账户。
  - 下半：「原始证据」可折叠卡（图片占位 + 原文）。关联候选卡片：支持 / 排除 / 仍需资料（iPhone 上提示「将发送到 Mac 处理」）。
  - 底部固定操作栏（模糊材质）：「暂放」次按钮、「保存并下一笔」主按钮；保存后自动切换到下一条，并 toast「已保存 · 撤销」。
  - 支持左右滑动卡片区切换上一/下一笔（可选，简化实现亦可用按钮）。
- 列表行支持左滑：「暂放」。

### 交易
- 常驻搜索栏；scope「交易 ｜ 原始资料」；右上筛选按钮 → sheet（账户、分类、标签、视图）；已生效筛选 chips 显示在列表顶部。
- 按日期分组列表，组头当日合计。
- 详情：金额大字、信息分组列表、生命周期时间线、原始证据；底部「编辑」→ 弹出与待办相同的编辑器（sheet）。

### 我的
分组列表：
- 家庭同步（状态行：「已同步 · 2 分钟前」；立即同步；同步目录；发往 Mac 的请求（2）；同步冲突）
- 家庭：成员、账户、来源归属规则
- 分类与标签：分类管理、标签规则
- FIRE 规划（只读完整视图；参数页可编辑但不是主路径）
- 备份与资料：本机副本备份、重新选择目录、资料检查
- 关于
每一项点进去显示一个简化但可信的子页面即可（列表 + 少量控件）。
